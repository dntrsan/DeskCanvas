# DeskCanvas v1.2.0-beta.1

Beta release for the desktop-widget update.

- Clock, Now Playing, and System Status widgets
- six persisted widget themes with opaque cards
- GSMTC transport, seek, artwork activation, stable timeline, and marquee
- real seven-band WASAPI loopback spectrum with smooth frame interpolation
- Simple and animated Wave timeline styles
- responsive System Status and compact resizable clocks
- legacy layout migration, safer in-place upgrade cleanup, and update notifications

This is a prerelease. The spectrum analyzes the Windows default output mix rather than an isolated per-application audio stream.
