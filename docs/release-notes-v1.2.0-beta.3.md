# DeskCanvas v1.2.0-beta.3

Beta 3 は、旧版から更新した後に旧版と新版が別々に残ったり、旧版だけが Windows サインイン時に起動したりする問題を修正したテスト版です。

## 更新内容

- 既知の正式インストール先を同じ AppId で上書きし、旧 `DeskCanvas.exe`、版番号付き実行ファイル、旧 DLL・runtime・言語ファイルを新しい本体の配置前に回収します。
- Run / RunOnce / StartupApproved / スタートアップショートカットに残った旧 DeskCanvas 登録を削除し、新しい `{app}\DeskCanvas.exe` への登録1件に統一します。
- `MyDeskCanvas.exe` など、名前が似ているだけの別アプリは削除対象にしません。
- アップグレード中の二重起動を避けるため、DeskCanvas が実行中の場合は共有 mutex で検出します。更新前に DeskCanvas を終了してください。
- `%LOCALAPPDATA%\DeskCanvas` のレイアウト、Media、Backups は保持します。
- 管理ウィンドウへ `v1.2.0-beta.3 BETA` を表示します。

## アップグレード検証

隔離したインストール先と専用レジストリで、v1.0.1 形式の旧ファイルと4種類の旧起動コマンド（通常名／版番号付き、引用符あり／なし）から更新しました。旧ファイルと旧起動登録が消え、新版の起動登録だけが1件残り、保存データが保持されることを確認しています。実PCの再起動は行わず、登録された最新版コマンドをログオン起動相当として実行して `DeskCanvas v1.2.0-beta.3 Beta` が起動することを確認しました。

## ダウンロード

通常は `DeskCanvas-Setup-1.2.0-beta.3.exe` を使用してください。ZIPはインストールせずに展開して使うポータブル確認用です。

このBetaは未署名のため、Windows SmartScreenの警告が表示される場合があります。
